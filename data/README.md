# Data Directory

The benchmark notebook should download or load the following real-world datasets:

- Energy
- AAPL log-returns
- Jena Climate
- ETTh1
- ETTm2
- Exchange Rate

Do not commit large raw datasets unless the data license allows redistribution. Prefer scripts or notebook cells that download public data sources and write a `dataset_manifest.csv` to `outputs/`.

Important: the reported protocol should not use synthetic fallback data.
