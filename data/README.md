# Data placement

This repository does not redistribute third-party raw datasets unless their license explicitly allows redistribution.

To rerun the notebook with the same declared real-world datasets, place the files below in this directory:

| Dataset | Expected local file | Required columns | Notes |
|---|---|---|---|
| Energy | `data/powerconsumption.csv` | `Datetime` and at least one `Zone*` or `*MW*` column | Tetouan/electrical power consumption style file. |
| AAPL | `data/aapl.csv` | `Date` and `Adj Close` or `Close`; optional `Symbol` | If a `Symbol` column exists, rows with `Symbol == AAPL` are used. The notebook transforms prices into log-returns. |
| Jena Climate | `data/jena_climate.csv` | `T (degC)` | Jena Climate temperature series. |
| Mackey--Glass | generated internally | none | Deterministic chaotic benchmark generated by the notebook. |

In Kaggle, the notebook also checks these paths:

- `/kaggle/input/electrical-power-consumption/powerconsumption.csv`
- `/kaggle/input/sp-500-stocks/sp500_stocks.csv`
- `/kaggle/input/jena-climate-2009-2016/jena_climate_2009_2016.csv`

The manuscript reports the full-run results exported in `outputs/`. Fallback logic in the notebook is intended only for diagnostic pipeline testing and should not be used to claim reproduction of the reported real-data benchmark.
