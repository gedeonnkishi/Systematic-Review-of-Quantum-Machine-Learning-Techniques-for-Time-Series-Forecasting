# Limitations and Scope

This repository supports a bounded proof-of-concept benchmark.

The CeNN framework is a classical functional emulator. It does not:

- simulate a quantum state vector or density matrix;
- reproduce genuine quantum entanglement;
- implement unitary quantum evolution;
- demonstrate quantum computational advantage;
- establish industrial readiness;
- replace physical QPU validation.

The reported benchmark does not establish universal generality. Future validation should include additional datasets, multivariate settings, longer and shorter horizons, distribution-shift tests, stronger QELM teachers, noise-aware simulations, and physical QPU comparisons.
